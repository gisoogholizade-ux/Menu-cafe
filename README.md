# Menu Cafe

منوی دیجیتال فارسی و RTL برای کافه با ظاهر تیره و الهام‌گرفته از فضای Akatsuki.

## تکنولوژی
- PHP 8+
- SQLite
- Vanilla JavaScript
- CSS Responsive / Mobile First
- بدون Node.js، Java، Docker یا VPS

## امکانات
- منوی عمومی مناسب QR
- جست‌وجوی لحظه‌ای
- فیلتر دسته‌بندی
- کارت محصولات و Bottom Sheet جزئیات
- نمایش وضعیت موجود/ناموجود
- ۱۲ آیتم نمونه فارسی
- پنل مدیریت `/admin`
- افزودن، ویرایش و حذف محصول
- تغییر قیمت و موجودی
- آپلود تصویر با پیش‌نمایش
- مدیریت دسته‌بندی‌ها و ترتیب نمایش
- QR منوی عمومی + دانلود
- تغییر رمز مدیر
- محافظت CSRF
- جلوگیری از اجرای PHP در پوشه uploads
- جلوگیری از دسترسی مستقیم به دیتابیس در Apache

## اجرای لوکال
اگر PHP روی سیستم نصب است، از ریشه پروژه اجرا کنید:

```bash
php -S localhost:8000
```

سپس:
- منو: `http://localhost:8000/`
- مدیریت: `http://localhost:8000/admin/`

## ورود اولیه مدیریت
- Username: `admin`
- Password: `ChangeMe123!`

**بعد از اولین ورود حتماً رمز را از بخش امنیت تغییر دهید.**

## نصب روی هاست معمولی
1. فایل‌های پروژه را داخل `public_html` یا یک پوشه از آن آپلود کنید.
2. PHP 8 یا جدیدتر را فعال کنید.
3. افزونه‌های `pdo_sqlite` و `fileinfo` باید فعال باشند.
4. مطمئن شوید پوشه‌های `data` و `uploads` اجازه نوشتن توسط PHP دارند.
5. سایت را یک بار باز کنید؛ دیتابیس و اطلاعات نمونه به‌صورت خودکار ساخته می‌شوند.
6. وارد `/admin` شوید و محصولات نمونه را با منوی واقعی کافه جایگزین کنید.
7. در `config.php` مقدار `menu_url` را روی URL نهایی منو قرار دهید تا QR همیشه آدرس درست را بسازد.

نمونه:

```php
'menu_url' => 'https://example.com/menu/',
```

## نکات انتشار
- قبل از تحویل نام کافه و tagline را در `config.php` تغییر دهید.
- تصاویر واقعی آیتم‌ها را از پنل مدیریت آپلود کنید.
- برای HTTPS از SSL هاست استفاده کنید.
- اگر هاست Apache نیست، دسترسی وب به پوشه `data` را از تنظیمات سرور مسدود کنید.
- فایل SQLite تولیدشده را داخل Git commit نکنید.
